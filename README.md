# GonzagaCPSC222-final-project

### Project Description

This is my take on the "Quantified-Self" final project for CPSC 222 (Introduction to Data Science). I decided to take twice-a-day 60-second typing tests for over two months straight, then analyze that data in this project. I cleaned the data, merged it with a "Days of the Week" table, performed visualizations, hypothesis tests, and classified my data with kNN and decision tree classifiers.

### How To Run

First, make sure you have the jupyter notebook, utils file, and two csv files downloaded. Then, to run this project, open the jupyter notebook and click the "Run All" button.  
This project uses numpy, pandas, matplotlib, scipy, and sklearn, so make sure you can easily use those as well.

### How it's Organized

The jupyter notebook titled "FinalProject.ipynb" holds the narrative of my final project, using data from "typing_4-30-26.csv" & "days_of_the_week_2-9-26_4-30-26.csv", along with splitting up repetitive or longer segments of code into the "utils.py" file. The jupyter notebook file begins with an introduction then transitions into data preparation, exploratory data analysis, classification results, and lastly, a conclusion & sources.
